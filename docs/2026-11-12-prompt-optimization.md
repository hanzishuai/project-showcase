# 2026-11-12 提示词针对本项目优化

## 结论

移植过来的提示词原本是 PP7 原样（只在 `.env` 换了助手名字），本次按本项目的实际情况做了针对性优化：
**去掉了写死的「邯郸学院」、把平台名做成配置、去掉过时示例与播报标签词、明确来源由界面展示、精简 23%，并补上了启动预热与空回答兜底。**

- PROMPT_VERSION：`2026-11-11.3` → `2026-11-12.1`（`/api/v1/rag/health` 可查）
- 系统提示词：2346 字 → **1801 字（-23%）**
- 「邯郸」出现次数：1 → **0**
- 示例：5 条（全绑定当前知识库）→ 2 条中性结构示例

## 优化前实测到的 5 个问题

| # | 问题 | 实测 |
|---|---|---|
| 1 | 身份自相矛盾 | 提示词第一句是「你是「软件学院项目实践聚合平台助手」，服务于**邯郸学院**项目实践聚合平台」。问「你是哪个学校的助手？」答「我是**邯郸学院**项目实践聚合平台的助手」 |
| 2 | 推荐问题提示词写死 | `build_suggestions_prompt()` 里固定「邯郸学院项目实践聚合平台」 |
| 3 | 示例会过期 | 5 条示例全是产教融合服务平台的细节，示例 1 直接断言「资料里目前记录的项目只有一个」 |
| 4 | 播报标签词 | 回答里出现「结论：」「一是定位：」，朗读生硬 |
| 5 | 冷启动首问空回答 | 重启后第一次提问返回空内容（UI 显示「（空回答）」），且没有错误提示 |

## 改了什么

| 文件 | 改动 |
|---|---|
| `backend/pp7rag/engine/prompts.py` | 重写：身份/平台名参数化；把「资料与引用」合并成一段并去重（原来「不编造」重复 4-5 次）；新增「来源由界面展示，不要念文档名/编号」；新增「不要用『结论：』『一是定位：』这类标签词」；示例从 5 条减到 2 条且改用 `【占位符】`；`build_suggestions_prompt` 改用配置的平台名；PROMPT_VERSION 升级 |
| `backend/pp7rag/config.py` | 新增 `rag_platform_name`（`RAG_PLATFORM_NAME`）；默认助手名改为更短的「平台助手」，避免「X 平台的 AI 助手」式重复 |
| `backend/app/main.py` | lifespan 里加 `_warmup_rag()`：后台预热嵌入模型 + LLM/TTS/HTTP 连接（失败只记日志，不阻塞启动） |
| `backend/pp7rag/ragapi/service.py` | 模型返回空正文时不再照常 `done`，改为发 `error` 事件（「模型这次没有返回内容，请再问一次。」），前端不再是「（空回答）」 |
| `backend/.env` | `RAG_ASSISTANT_NAME=平台助手`、`RAG_PLATFORM_NAME=软件学院项目实践聚合平台` |

## 改完实测

| 问题 | 优化前 | 优化后 |
|---|---|---|
| 你是哪个学校的助手？ | 「我是邯郸学院项目实践聚合平台的助手」 | 「我是软件学院项目实践聚合平台的助手。」 |
| 平台上有哪些项目？ | （首次冷启动返回空） | 「资料里只记录了一个项目：产教融合服务平台。一是定位…二是内容…三是状态…资料里没有记录其它项目，所以不列。」 |
| 这个平台怎么对接企业？ | 正常 | 正常，且结尾主动提示「平台还没正式上线」 |
| 平台现在正式上线了吗？ | 正常 | 正常，带 20 条/20 条/9 个领域口径与「资料里没有明确的上线日期」 |
| 详细说说正式上线还要做什么？ | 出现「结论：」标签 | 无标签词，分三点 + 顺序说明 + 计划不等于承诺 |
| `/suggestions` | 提示词写死邯郸学院 | 正常生成，无邯郸 |

其他验证：

- `/health` 返回 `prompt_version=2026-11-12.1`，各项能力 true；
- 冷启动：重启后立刻提问正常返回（不再空回答）；
- 浏览器实测：回答无 `pageerror` / `console.error`，来源行仍是一行「来源：产教融合服务平台」；
- 预先算过：系统提示词省了约 500 字，每次请求的输入 token 相应减少。

## 没做的部分

- **知识库与看板不一致**：按需求明确不处理（看板卡片是演示数据，随便写的），数字人只按知识库回答。
- 没有改检索参数（top_k=3、reference 600 字、short 220 字 / detailed 700 字）。

## 回退方式

1. 只想临时换提示词：在 `backend/.env` 设 `GUIDE_SYSTEM_PROMPT`（文本或文件路径）整段覆盖，无需改代码；
2. 完全回退：`git checkout -- backend/pp7rag/engine/prompts.py backend/pp7rag/config.py backend/app/main.py backend/pp7rag/ragapi/service.py`，并把 `.env` 里的 `RAG_ASSISTANT_NAME` 改回长名字。
